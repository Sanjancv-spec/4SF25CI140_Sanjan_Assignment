## Overview
This repository contains solutions to the 13 core Pandas assignment problems covering:
1. DataFrame creation and column arithmetic (product of columns).

3. Handling missing values via mean imputation (`fillna(df.mean())`).
4. Dropping missing records (`dropna()`).
5. GroupBy aggregations computing sum and mean metrics.
6. Categorical sales grouping.
7. Relational DataFrame merging on a shared key (`pd.merge`).
8. MultiIndex creation, hierarchical slicing, and `.loc` indexing.
9. Multi-level index summation.
10. Applying custom transformation functions element-wise.
11. Column summation across rows using Lambda functions.
12. Vectorized string manipulations (case conversion via `.str.upper()`).
13. String slicing and substring extraction (`.str[:3]`).
